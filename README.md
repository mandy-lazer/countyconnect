# CountyConnect — Public Service Request System

CountyConnect is a Django-based web application inspired by Kenya's eCitizen platform. It allows citizens to access county services, submit service requests, and track their progress online.

## Key Features

- **User Accounts:** Citizen registration, login, and authentication.
- **County Departments:** Services organized under county departments.
- **Service Requests:** Citizens can submit requests and view their submissions.
- **Request Tracking:** Citizens can check request status and view request details.
- **Staff Management:** Authorized staff can view requests and update their status.
- **Email Notifications:** Email verification and notifications where configured.
- **File Uploads:** Support for request images using Cloudinary storage.

## Technology Stack

- Python and Django
- PostgreSQL with Neon
- HTML, CSS, Bootstrap, and Django templates
- Git and GitHub
- Vercel deployment
- Cloudinary for image storage

## County Departments

- Health Services
- Land and Physical Planning
- Public Works
- Revenue and Licensing
- Roads and Transport
- Water and Sanitation

The services available under each department depend on the services configured in the database.

## Project Goal

To simplify access to county public services by providing a centralized platform for submitting requests, tracking progress, and improving communication between citizens and county staff.
