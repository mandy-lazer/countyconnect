# CountyConnect

A Django-based Public Service Request System inspired by Kenya's eCitizen platform.

## Features

- Citizen account management
- Browse county departments and services
- Submit and track public service requests
- View request status and progress
- Staff request management and status updates
- Email notifications

## Technology Stack

- Python
- Django
- PostgreSQL
- HTML, CSS, Bootstrap

## Local Development

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
